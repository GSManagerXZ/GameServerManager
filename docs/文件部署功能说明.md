# 文件部署

## 功能概述

“游戏部署”页面的“文件部署”支持上传压缩包和 URL 离线下载两种来源。系统会在游戏默认安装路径下使用游戏名称创建目录，解压文件后创建或更新实例。

“云构建部署”已从前端标签页隐藏，原有云构建后端接口和代码仍保留。

## 使用流程

1. 打开“游戏部署”中的“文件部署”。
2. 选择“上传压缩包”或“URL 离线下载”。
3. 填写游戏名称。目标目录为“默认游戏安装路径/游戏名称”。
4. 选择实例类型：通用、Minecraft Java 版或 Minecraft 基岩版。
5. 通用实例需要填写启动命令；Java 版可选择已安装的 Java 环境。
6. 点击开始部署，按弹窗选择目录和实例冲突处理方式。

## 支持的压缩格式

- `.zip`
- `.7z`
- `.tar`
- `.tar.gz` / `.tgz`
- `.tar.xz` / `.txz`

压缩包如果只有一层包装目录，会自动去掉该层，其余文件和子目录层级保持不变。

## 目录冲突

- **合并覆盖**：压缩包中的文件覆盖同名旧文件，旧目录中其他文件保留。
- **删除后重装**：压缩包下载和安全解压完成后删除旧目录，再放入新文件。
- **取消**：不修改旧目录，终止本次操作。

## 实例冲突

同名实例存在时，可以选择更新已停止的实例，或仍然新建同名实例。运行中、正在启动或正在停止的实例不允许在部署流程中更新，需先在实例管理中停止实例。

## URL 离线下载注意事项

- 仅支持 HTTP 和 HTTPS URL，会跟随重定向。
- 服务端会根据 `Content-Disposition`、最终 URL 和原始 URL 识别文件名。URL 无法识别支持的扩展名时会拒绝部署。
- 当前允许公网和局域网地址，请仅在可信管理员可访问面板时使用。
- 下载中可以点击取消，系统会删除下载和解压临时文件。
