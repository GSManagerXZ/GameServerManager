# GSM3 多架构支持说明

## 概述

GSM3 游戏服务端管理面板支持在多种 Linux 架构上部署。AMD64 仍是完整功能目标；ARM64 和 RISC-V64 更适合作为轻量 Web 管理面板或远程管理节点。不同架构的原生依赖、SteamCMD 和游戏服务端可用性并不相同，部署前应按下表确认。

## 架构对比

| 功能 | AMD64 (x86_64) | ARM64 (aarch64) | RISC-V64 (riscv64) | 说明 |
|------|----------------|-----------------|--------------------|------|
| GSM3 Web 管理界面 | 支持 | 支持 | 支持 | RISC-V64 需要系统预装 Node.js >= 18 |
| 发布安装包 | `linux-x64` | `linux-arm64` | `linux-riscv64` | RISC-V64 包不内置 Node.js |
| 内置 Node.js 22 | 支持 | 支持 | 不支持 | Node.js 官方 v22.17.0 未提供该项目当前使用的 linux-riscv64 预编译包 |
| 固定 PTY 资产 | 支持 | 支持 | 暂无 | RISC-V64 终端功能在缺少上游 PTY 资产时降级为不可用 |
| Zip-Tools / 7z 内置资产 | 支持 | 支持 | 暂无 | RISC-V64 运行时会尝试使用系统 `unzip`、`zip`、`7z`/`7zz` |
| SteamCMD | 支持 | 不支持 | 不支持 | SteamCMD 官方主要面向 x86 Linux |
| 游戏服务器依赖 | 支持 | 取决于游戏 | 取决于游戏 | 大多数商用游戏服务端只发布 x86_64 构建 |
| Docker 镜像 | 支持 | 支持 | 暂不声明支持 | Dockerfile 仍只声明 AMD64/ARM64 |

## 快速检查

```bash
uname -m
node -v
command -v unzip zip 7z 7zz
```

架构映射：

- `x86_64` / `amd64` -> `linux-x64`
- `aarch64` / `arm64` -> `linux-arm64`
- `riscv64` -> `linux-riscv64`

## 构建安装包

```bash
# AMD64
npm run package:linux:x64

# ARM64
npm run package:linux:arm64

# RISC-V64
npm run package:linux:riscv64
```

仅生成目录、不创建 zip：

```bash
npm run package:linux:riscv64:no-zip
```

RISC-V64 包内已经包含服务端生产依赖，但不会包含 Node.js、PTY、Zip-Tools 或 7z 原生资产。目标机器需要预先安装：

```bash
sudo apt-get update
sudo apt-get install -y nodejs npm unzip zip p7zip-full
```

不同发行版的软件包名称可能不同；最低要求是 `node` 版本 >= 18。若只需要启动 Web 管理面板，`zip`、`p7zip-full` 可稍后按需安装。

## 部署方式建议

### AMD64

- 适合作为完整游戏服务器管理节点。
- 可使用 Docker 或发布安装包。
- SteamCMD、常见游戏服务端和 i386 兼容库支持最完整。

### ARM64

- 适合作为轻量 Web 管理面板、远程监控和配置节点。
- 发布安装包内置 Node.js 与当前 ARM64 原生资产。
- SteamCMD 和大多数 x86 游戏服务端不可用。

### RISC-V64

- 适合作为 Web 管理面板或架构适配测试节点。
- 推荐使用发布安装包或本地源码运行，不建议把 Docker 视为已支持路径。
- 终端 PTY 依赖上游提供 riscv64 资产；在资产缺失时，服务可启动，但终端创建功能会不可用。
- ZIP 解压可使用系统 `unzip` 降级；ZIP 压缩需要系统 `zip`；7z 功能需要系统 `7z` 或 `7zz`。

## 功能限制

1. **SteamCMD 限制**
   - 非 x86_64 架构不要默认承诺 SteamCMD 可用。
   - 即使面板可运行，游戏服务端是否能运行仍取决于游戏厂商是否提供对应架构构建。

2. **原生资产限制**
   - 新增架构前，需要逐项确认 Node.js、PTY、Zip-Tools、7z、Java 和游戏运行时。
   - 没有上游资产时，应明确降级或禁用对应功能，而不是下载错误架构的二进制。

3. **RISC-V64 前置条件**
   - 需要系统 Node.js >= 18。
   - 如需压缩/解压功能，安装 `unzip`、`zip`、`p7zip-full` 或发行版等价包。
   - PTY 终端功能等待上游 riscv64 资产后才能完整支持。

## 故障排除

### Node.js 缺失

```bash
node -v
```

如果命令不存在或版本低于 18，请先安装发行版提供的 Node.js，或使用该发行版推荐的 Node.js 安装方式。

### ZIP/7z 功能不可用

```bash
command -v unzip
command -v zip
command -v 7z || command -v 7zz
```

RISC-V64 上没有内置 Zip-Tools/7z 资产，系统命令不存在时，对应压缩或解压任务会失败并给出安装提示。

### Docker 架构不匹配

```bash
docker image inspect xiaozhu674/gameservermanager:latest | grep Architecture
docker pull --platform linux/amd64 xiaozhu674/gameservermanager:latest
docker pull --platform linux/arm64 xiaozhu674/gameservermanager:latest
```

当前 Docker 镜像只声明 AMD64 和 ARM64。不要在发布说明中把 RISC-V64 Docker 作为已支持能力。
