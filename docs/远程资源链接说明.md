# 远程资源链接说明

面板有一部分数据不再取自旧的第三方接口，而是改为从文件站点 `https://web.files.xiaozhuhouses.asia` 拉取静态 JSON。为避免多处硬编码出现链接不一致，这些地址统一维护在 `server/src/utils/remoteSources.ts`。

## 当前链接

| 用途 | 使用位置 | 链接 |
| --- | --- | --- |
| 实例市场（Linux） | 实例管理 → 实例市场、游戏部署安装时匹配启动命令、插件 API | `https://web.files.xiaozhuhouses.asia/files/开源项目/GameServerManager/Instance/Instance_Linux.json` |
| 实例市场（Windows） | 同上，Windows 平台自动选择 | `https://web.files.xiaozhuhouses.asia/files/开源项目/GameServerManager/Instance/Instance_Windows.json` |
| Steam 游戏部署清单 | 设置页“更新Steam游戏部署清单”、定时任务“更新Steam游戏部署清单”、游戏部署页“更新游戏清单”和清单缺失时的自动更新 | `https://web.files.xiaozhuhouses.asia/files/开源项目/GameServerManager/installgame.json` |
| 一键开服清单 | 游戏部署 → 一键开服（原“在线部署”） | `https://web.files.xiaozhuhouses.asia/files/开源项目/GameServerManager/oneClickDeploy.json` |

## 代码入口

`server/src/utils/remoteSources.ts` 导出：

| 导出项 | 说明 |
| --- | --- |
| `STEAM_GAME_LIST_URL` | Steam 游戏部署清单（`installgame.json`）地址，所有“更新清单”入口共用 |
| `INSTANCE_MARKET_URLS` | 实例市场清单地址，按 `Linux` / `Windows` 区分 |
| `ONE_CLICK_DEPLOY_LIST_URL` | 一键开服清单地址，由 `server/src/utils/oneClickDeploySource.ts` 负责拉取与缓存 |
| `getInstanceMarketSystemType()` | 根据当前运行平台返回清单类型 |
| `getInstanceMarketUrl(systemType?)` | 返回实例市场清单地址，未知平台回退到 Linux 清单 |
| `fetchInstanceMarketList(systemType?, options?)` | 拉取实例市场清单，返回 `instances` 数组；`options` 支持 `timeoutMs`（默认 10 秒）与 `userAgent` |

### 引用位置

- `server/src/routes/instances.ts`：`GET /api/instances/market`（面板“实例市场”标签页）
- `server/src/routes/pluginApi.ts`：`GET /api/plugin-api/instances/market`（插件 API）
- `server/src/routes/gameDeployment.ts`：
  - `POST /api/game-deployment/install`：安装/更新 Steam 服务端时按游戏名匹配市场启动命令（超时 5 秒，失败自动回退本地清单启动命令）
  - `GET /api/game-deployment/games`：本地 `installgame.json` 缺失时自动下载
  - `POST /api/game-deployment/update-game-list`：设置页与游戏部署页的“更新清单”按钮
- `server/src/modules/scheduler/SchedulerManager.ts`：定时任务系统操作 `steam_update`（“更新Steam游戏部署清单”）

## 数据结构约定

- 实例市场清单：`{ "instances": [ { "name": string, "command": string, "stopcommand": string } ] }`
- 游戏部署清单：`{ "<gameKey>": { "game_nameCN": string, "appid": string, ... } }`，更新前会校验首条记录是否含 `game_nameCN` 与 `appid`
- 一键开服清单：`{ "schemaVersion": number, "updatedAt": string, "notice": string, "games": [ { "id": string, "name": string, "download": { "url": string, "platforms": { "<平台>": { "url": string } } } } ] }`，完整字段见 [一键开服说明.md](一键开服说明.md)

## 更换链接的方式

只修改 `server/src/utils/remoteSources.ts` 中的 `FILES_BASE_URL`、`PROJECT_DIRECTORY`，或直接改 `STEAM_GAME_LIST_URL` / `INSTANCE_MARKET_URLS` / `ONE_CLICK_DEPLOY_LIST_URL` 即可，所有入口同步生效，不需要再逐个文件修改。

修改后执行 `cd server && npm run build` 重新编译；若面板以打包产物运行，需要重启服务。
