# Windows 首页资源监控说明

## 背景

Windows 下首页资源监控会定期通过 PowerShell 获取 CPU、内存、磁盘和进程等系统状态。部分环境中，这些查询可能创建多个 PowerShell 进程并提高 CPU 占用，进而影响游戏服务运行。

## 默认行为

- Windows：未保存过此项设置时，首页资源监控默认关闭。
- 非 Windows：首页资源监控默认开启，保持原有行为。

## 使用方法

1. 打开面板的“设置”页面。
2. 在“网页设置”中找到“首页资源监控”。
3. Windows 用户启用时会看到性能风险提示；确认后，保存设置即可生效。

关闭后，首页不再订阅系统资源统计，因此不会显示 CPU、内存、磁盘和网络的实时统计卡片。端口与进程列表等其他首页功能不受影响。
